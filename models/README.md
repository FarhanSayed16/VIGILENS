# Model weights

Do **not** commit large weight files.

MVP models download automatically when packages run:

- **YOLOv8-pose** (`yolov8n-pose.pt` / `yolov8s-pose`) via Ultralytics  
- **MediaPipe Face Landmarker** via MediaPipe Task API  

Store downloaded weights here or in the library cache. See `docs/AIML_CONFIRMATION.md`.
